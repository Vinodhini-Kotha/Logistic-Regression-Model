# Logistic Regression Base Model (From Scratch)

This repository contains a basic implementation of Logistic Regression from scratch using Gradient Descent in Python (Jupyter Notebook).

No external dataset is included. The notebook focuses only on the core algorithm implementation.

## Features
- Sigmoid function
- Log loss (cost) function
- Gradient Descent optimization
- Model training (fit)
- Prediction function

## File
- logistic_regression_base.ipynb : contains the full implementation

## Requirements
- Python 3
- NumPy

## How to Run
1. Open the notebook:
   jupyter notebook logistic_regression_base.ipynb
2. Run all cells.

## Purpose
This repository is intended for learning and understanding how Logistic Regression works internally using Gradient Descent.
